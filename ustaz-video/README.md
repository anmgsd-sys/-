# «Ұстазым» — 1-куплет + қайырма лирик-видеосы

`render.py` толық кодпен (Python + Pillow + ffmpeg) видео жасайды:

* Кіріспе мәтін жоқ — видео бірден ән сөзімен басталады (әннің 6.9-секундынан).
* **Куплет (6.4–30.2 с)** — сілтеме видеодағыдай чат стилі: сөздер жолаққа айтылған уақытында теріледі,
  біткен жол хабарлама болып жоғары ұшады; әр сөзге стикер (күнтізбе «11», рюкзак, мектеп, көгершін, бітіру қалпағы, ұстаз, есік, қоңырау, өскін, шам, 100).
* **Қайырма (30.2–54.5 с)** — сөздер біресе ҮЛКЕН, біресе кішкентай (кинетикалық типография), мәтін кезек солға/оңға шығады, астында қызғылт жүгіртпе жол,
  әр сөзге стикер (жүрек, құм сағат, жол, медаль, күн, көгершін, әліппе, кітап, гүл шоғы, мектеп).
* **Соңы** — мектеп ғимараты + стикерлер.

Барлық анимация 121 BPM ырғақ торына байланған (стикерлер әр соққыда «секіреді», қайырмаға кірерде жарқыл + сілкіну).

## Іске қосу
```bash
pip install pillow numpy          # ffmpeg және Inter қаріпі керек
python3 render.py --audio ән.mp3 --out ustazym.mp4
python3 render.py --audio ән.mp3 --preview 9.8 31.5   # жекелеген кадрлар
```

## Мәтінді түзету
`lyrics.json` ішінде `text` өрістерін (қайырмада `!` — ҮЛКЕН, `~` — орташа, `/` — жаңа жол) түзетіп, қайта рендерлеңіз.
Әр сөздің уақыты `w*` тізімдерінде (секунд), стикерлер `stickers` тізімінде.
